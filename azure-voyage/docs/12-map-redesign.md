# 12 — 地圖縮編計畫（M21）

> 回應玩家回饋：「地圖太小城市太多，預期 10~20 城市就好」。
> 本文件記錄縮編理由、對照表、與美術風格待辦（衛星空拍視覺，尚未執行）。

## 0. 決策記錄

玩家原本也提出「改成西歐地中海為中心＋真實港口＋Google Earth/Google Map 風格圖像」，
經溝通後確認：

- **地理維持架空**：真實地中海地理會讓遊戲性質滑向「大航海時代換皮」，直接牴觸
  這個專案從一開始的核心版權安全網（docs/11 §0 已有相同結論）。地名、航線、地理
  全部保持原創。
- **直接嵌入 Google Earth/Google Map 圖磚不可行**：那些圖磚有嚴格使用條款，
  不能當美術資產直接放進遊戲。
- **視覺方向**：之後若要做「衛星空拍質感」，走既有的 AI 生圖管線（`tools/artgen`）
  產出「衛星空拍風格的架空世界地圖」，地理仍是原創——這件事尚未執行，見 §3 待辦。
- **城市數**：確定縮編，本次先處理這件事。

## 1. 港口縮編（40 → 15）

原規劃 40 港（每海域 5–6 個）分散了經濟/勢力/酒館內容的密度，玩家覺得城市多但
單一港口存在感低。縮編到 **15 港**（每海域 2–3 個，玩家起始海域琥珀灣保留 3 個），
只留規模 1 與規模 3（首都）為主、少量規模 2，讓每個港口更有記憶點。

被刪港口的 `produces`（特產）合併進同海域保留下來的港口，**全 36 種商品仍各自
至少有一個產地**（`worldgen.test.ts` 的 `every commodity has at least one origin port`
持續驗證這件事）。

| 海域 | 保留 | 刪除（特產已合併進保留港口） |
|------|------|------|
| 北環海 | 霜港(s3)、瓦爾德倫(s2) | 賽斯卡、艾德摩爾、科爾維克、布倫洛 |
| 琥珀灣 | 奧雷利亞(s3，首都/起始港)、米倫港(s2)、佩爾蘭(s1) | 卡斯特蘭、索爾梅、維雷諾 |
| 鐵崖海岸 | 杜恩哈(s3)、塔恩維克(s2) | 克拉格、莫爾凡、石臂港、格雷文霍姆 |
| 絹風海峽 | 賽琳德拉(s3)、凱什瓦(s2) | 塔洛米爾、溫夏爾、伊爾科羅、瑪什凱 |
| 子午之海 | 薩夫蘭(s3)、巴索羅(s2) | 卡爾維爾、奧科羅、席爾沼港、塔洛溫 |
| 珊瑚環弧 | 瑪魯亞環礁(s2)、歐奈斯(s1) | 特利瓦伊、卡瓦魯、拉瓦貝港 |

## 2. 影響範圍檢查（實作時已逐一確認）

- **世界地形（hexmap.json）**：不動。保留的 15 個港口座標都沿用原本 40 港裡
  已驗證過的岸邊格，不需要重新產生地形。
- **發現物（discoveries.ts）**：不綁定港口，只綁定海圖座標（外洋位置），不受影響。
- **NPC 影響力初始分布（worldgen.ts `buildInfluences`）**：依 `PORTS` 動態產生，
  縮編後自動套用，不需改邏輯。
- **酒館待業航海士池（`buildTavernOfficers`）**：依 `port.size >= template.minPortSize`
  篩選，15 港仍涵蓋 size 1/2/3，12 個航海士模板都還有地方出現。
- **`tools/artgen` manifest**：港口場景資產用 `<regionId>-s<size>` 命名（M18 起），
  縮編後每海域仍是同一組 size 組合，**不需要補新圖**。
- **測試**：`worldgen.test.ts` 三處寫死 `40` 的斷言改成動態比對 `PORTS.length`；
  `voyage.service.spec.ts` 的 `NORTH_PORT_ID` 測試夾具從已刪除的賽斯卡改指向
  瓦爾德倫；其餘測試檔案裡出現的港口 id 字串剛好都指向保留下來的港口，未受影響。

## 3. 待辦

- **美術風格**：目前地圖仍是 M15 的六角格程式繪製風格；「衛星空拍質感」尚未執行，
  之後有需要再開新里程碑，走 `tools/artgen` 生圖管線（風格前綴另外設計，地理維持
  架空，不使用任何真實地圖圖磚）。
