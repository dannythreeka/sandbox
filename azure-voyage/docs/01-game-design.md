# 01 — 遊戲設計文件（GDD）

本文件定義所有遊戲規則。**05-game-engine.md 的演算法、03-data-model.md 的欄位都由本文件推導**，規則若有調整需三份文件同步。

## 1. 世界觀（原創）

架空星球「泛瀾世界」的內海文明圈——**蒼瀾海域**。大陸環抱一片巨大的內海與外洋群島，七大海域、15 個港口（M21 執行記錄：原規劃 40 港，實作後依玩家回饋精選縮編，理由與縮編對照見 docs/12 §1）。時代背景類似「帆船黃金時代」的架空版本：羅盤與星圖剛剛成熟，外洋仍是傳說之地。

七大海域（原創地名，實作時可再調整）：

| 海域代碼 | 名稱 | 特色 |
|---------|------|------|
| `NORTH_REACH` | 北環海 | 漁獲、木材、琥珀；冬季風暴多 |
| `AMBER_GULF` | 琥珀灣 | 文明中心，金融與工藝品 |
| `MERIDIAN_SEA` | 子午之海 | 香料轉運樞紐，海賊活躍 |
| `CORAL_ARC` | 珊瑚環弧 | 群島地形，珍珠與染料 |
| `DUSK_EXPANSE` | 暮色洋 | 外洋，未知海域多，發現物豐富 |

**NPC 商會（玩家的對手，5 個）**：每個商會有起始地盤與「性格參數」，性格由 AI Agent 扮演（見 06）。範例：北方的「霜港同盟」保守重防禦、子午海的「緋帆團」半商半盜激進擴張……（名稱原創，實作時生成完整設定）。

## 2. 勝利與失敗

- **勝利條件（v1）**：任一達成 → (a) 在 7 大海域中的 4 個海域取得「海域霸權」（該海域內影響力總和第一且 >40%）；(b) 收集「傳世遺物」級（S 級）發現物；(c) 總資產達到目標值（依難度）。
  （M22 執行記錄：發現物總數配合內容規模落在 23 件，S 級「傳世遺物」共 3 件，(b) 門檻相應調整為登錄滿 3 件，原規劃的 12 件是對應 40 港時代較大內容量的數字，詳見 docs/14。）
- **失敗條件**：破產（現金 < 0 且無船可賣）持續 30 tick，或旗艦沉沒且無力再購船。

## 3. 核心循環（Core Loop）

```
出港準備（補給/僱船員/裝貨）
   → 海上航行（tick 前進：耗糧水、遇事件、可探索）
   → 抵達港口（時間暫停）
   → 港內行動（交易獲利 / 投資拉影響力 / 酒館情報與招募 / 造船改裝）
   → 影響力版圖變化 → 解鎖更深的海域與更大的商機
   → 回到出港準備
```

單局目標節奏：前期跑短程貿易累積資本 → 中期建立多艦隊、搶影響力 → 後期外洋探索 + 與 NPC 商會決戰。

## 4. 系統規格

### 4.1 航海系統

- 海圖是 **hex 網格**（六角格，建議半徑 ~120x80 格），每格有地形：深海 / 淺海 / 暗礁 / 港口 / 陸地。Hex 讓移動與風向計算簡單且好看。
- 每 tick（=1 天）艦隊移動 N 格：`N = base_speed × wind_modifier × condition_modifier`，取整、剩餘進位累積。
  - `base_speed`：艦隊中最慢船隻的速度值 / 10（速度 30 → 3 格/天）。
  - `wind_modifier`：順風 1.3 / 側風 1.0 / 逆風 0.6。每個海域每季有主風向（確定性資料）+ 每日隨機擾動。
  - `condition_modifier`：船體耐久、船員士氣低落時 0.5–1.0。
- **補給消耗**：每 tick 每名船員消耗 1 糧 + 1 水（單位抽象化）。歸零→士氣暴跌→每 tick 隨機減員→可能叛變（GAME EVENT）。
- **航行事件**（每 tick 擲骰，機率由海域危險度、季節、瞭望員技能修正）：風暴（船體/貨物損失）、海賊遭遇（→海戰或繳費）、漂流物、鯨群/奇景（士氣+）、AI 生成特殊事件（低機率，見 06）。
- 玩家操作模式：點擊海圖目的地 → 前端 A* 尋路產生航線 → 送後端驗證並儲存 → 之後每 tick 後端沿航線推進。玩家可隨時改道。

### 4.2 貿易與經濟系統

- 每個港口的市場販售 4–8 種交易品。交易品共 ~36 種、分 8 類（糧食、酒類、織品、礦石、武具、工藝品、奢侈品、香料）。
- **價格模型**（後端每 tick 演算，詳見 05）：

  `price = base_price × supply_demand_factor × regional_factor × event_factor × influence_discount`

  - `supply_demand_factor`：港口庫存 vs 基準庫存。玩家大量買入→庫存降→價格升（防刷單）。庫存每 tick 依生產/消耗率回歸基準。
  - `regional_factor`：距原產地越遠越貴（產地查表 + 海域距離矩陣）。
  - `event_factor`：事件影響（豐收、戰亂、流行→AI 事件可掛此鉤子，範圍夾限 0.5–2.0）。
  - `influence_discount`：玩家商會在該港影響力每 10% → 買價 -1%、賣價 +1%（上限 ±8%）。
- **關稅**：跨海域販售抽稅，稅率受該港控制商會與玩家關係影響。
- 貨艙：每艘船 `cargo_capacity`，糧水與商品共用空間 → 「帶多少補給 vs 載多少貨」的經典取捨。

### 4.3 影響力（佔有率）系統 —— 勝負核心

每港口有 100 點影響力池，各商會（玩家 + 5 NPC + 「在地勢力」）分食。

**提升手段**（玩家與 NPC 商會用同一套規則）：
1. **交易額累積**：在該港每完成一筆交易，累積「商譽點」，每 tick 結算轉化為影響力（邊際遞減）。
2. **港口投資**：花錢投資設施（碼頭/市場/造船廠），立即 + 影響力，效果隨已有影響力遞減。
3. **完成該港任務**（酒館委託、AI 生成事件）。
4. **擊退騷擾該港的海賊**。

**衰減與對抗**：影響力每 tick 自然衰減 0.1%；商會間在同港的影響力用「擠壓模型」——池滿時新增影響力按比例壓縮他會份額（在地勢力最軟，先被擠壓）。

**影響力帶來**：買賣價優惠、造船折扣、獨家商品解鎖（>50%）、港口稅收分紅（>30%，每 tick 入帳）、該港酒館出現更高級航海士。

**海域霸權**：海域內自會影響力總和第一且 >40% → 獲得海域 buff（該海域移動 +10%、事件早知情報）。

### 4.4 海戰系統（回合制）

- 進入條件：航行事件遭遇海賊 / 主動攻擊 NPC 艦隊 / 劇情戰。
- 戰場：hex 棋盤（半徑 7 的六角區域），我方艦隊 vs 敵方艦隊，每艘船是一個單位。
- 回合流程：以船隻「機動值」排序輪流行動；每回合每船可 `移動`＋`一個動作`：
  - `炮擊`：射程 2–4 格，傷害 = 火力 × 側舷角度加成 × 距離衰減 − 敵裝甲；打耐久或打帆（打帆降機動）。
  - `接舷`：相鄰格發動，轉為船員白刃戰（雙方船員戰力比 + 隨機，勝者可俘虜船隻）。
  - `修理`、`撤退`（從戰場邊緣脫離，逆風時較難）。
- 風向在戰場上同樣生效：順風移動 +1 格、逆風炮擊命中 −10%。
- 勝利：敵全滅/投降/撤退。戰利品：金錢、貨物、俘虜船（可編入或變賣）。**旗艦被擊沉=玩家艦隊敗北**，被拖回最近友好港、損失部分資產。
- 所有判定為確定性公式 + 種子隨機（seed 存在戰鬥實體上，可重放、可測試）。

### 4.5 航海士（夥伴）系統

- 屬性：`統率 / 航海 / 戰鬥 / 商才 / 學識`（1–100）+ 技能標籤（如「測繪」「炮術」「外語」「談判」…約 20 種）。
- 職位槽（每艦隊）：副官、航海長、炮術長、會計長、瞭望員 —— 職位把對應屬性/技能轉為艦隊 buff（M23 執行記錄：五個職位效果全數接上，對照表見 docs/15 §3）。
- 招募：酒館遇見（出現池受港口、影響力、聲望影響），部分高級航海士需完成 AI 生成的個人小任務才肯加入。
- 成長：參與航行/戰鬥/交易獲得經驗，屬性緩慢成長；忠誠度低 + 久未發薪 → 可能離隊（M23 執行記錄：經驗成長機制詳見 docs/15 §2）。
- 對話：航海士的閒聊與建議可由 AI 對話代理生成（風味層，不影響數值，見 06）。

### 4.6 探索與發現物系統

- 外洋與特殊格有「探索點」：需要 `學識` 足夠的航海士 + 消耗補給進行探索檢定。
- 發現物分類：地理（海峽/島）、生物、遺跡、天象；稀有度 C/B/A/S，S 級即「傳世遺物」（勝利條件之一）。
- 發現物登錄到「學會」（琥珀灣的機構）換取金錢、聲望與地圖情報。
- 發現物圖鑑文本由 AI 生成一次後**固化存檔**（同一世界內不重生成，控制成本與一致性）。

### 4.7 事件系統

三層事件來源，統一走同一條 `WorldEvent` 管線（見 05/06）：
1. **規則事件**（確定性/加權隨機）：風暴、行情波動、海賊出沒 —— 永遠可用，是 fallback 基底。
2. **AI 排程事件**：每 N tick，AI Orchestrator 根據世界快照生成 1–3 個候選事件（港口慶典、商會衝突、傳聞任務鏈），經驗證與數值夾限後入庫排程。
3. **AI 敘事包裝**：規則事件觸發後，AI 可為其生成一段風味文本（非阻塞，文本晚到就先用模板文案）。

## 5. 難度與平衡參數

所有平衡常數集中在 `packages/shared/src/rules/constants.ts`（單一真相來源），difficulty 檔（EASY/NORMAL/HARD）為常數表的乘數覆蓋。禁止在業務代碼中硬編碼數值。
